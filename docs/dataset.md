# OutMind Unified Dataset Specification

The official technical specification for **`Mesosfer/outmind-dataset`**, the multimodal and multilingual training corpus curated, cleaned, and standardized for the **OutMind** Small Language Model (SLM) ecosystem.

---

## 1. Executive Summary & Design Philosophy

Small Language Models (34M–125M parameters) are disproportionately vulnerable to low-quality, noisy, or unbalanced pretraining data. To maximize downstream reasoning capabilities under constrained compute budgets (Chinchilla-optimal scaling), the OutMind dataset enforces three fundamental architectural rules:

1. **Strict Three-Tier Isolation**: Pretraining, Supervised Fine-Tuning (SFT), and Evaluation Benchmarks reside in completely isolated partitions.
2. **Deterministic Data Hygiene (Audit Grade A - 91.5/100)**: All pretraining and instruction sources undergo automated regex sanitization, boilerplate copyright removal, and online deduplication before tokenization.
3. **Zero Test-Set Contamination**: Official evaluation benchmarks (GSM8K, HumanEval, MMLU, TyDiQA) are preserved 100% verbatim without any filtering or rewriting to guarantee honest, reproducible evaluation.

## 3. Tier 1: Pretraining Corpus Details

The pretraining mixture delivers balanced exposure across natural human languages, synthetic educational content, rigorous mathematical reasoning, and programming code:

| Corpus ID | Upstream Source | Language / Domain | Target Volume (Raw) | Compressed Size | Hygiene Pipeline |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **`id_wikipedia`** | `wikimedia/wikipedia (20231101.id)` | Indonesian | **~1.8 GB** (100% Full) | ~548 MB (5 parts) | Strips footers (`== Referensi ==`), navigation bars, and citation brackets (`[1]`, `[catatan 2]`). |
| **`zh_wikipedia`** | `wikimedia/wikipedia (20231101.zh)` | Chinese | **~2.5 GB** (100% Full) | ~1.62 GB (10 parts) | Strips reference sections, normalizes CJK punctuation, and enforces UTF-8. |
| **`en_cosmopedia`** | `HuggingFaceTB/smollm-corpus` | English (Synthetic) | **~5.0 GB** | ~3.26 GB (21 parts) | Curated synthetic textbooks, stories, and academic summaries generated by Mixtral. |
| **`code_python`** | `codeparrot/codeparrot-clean` | Python Code | **~5.0 GB** | ~1.86 GB (21 parts) | Strips license/copyright comment blocks (`## Copyright`) while preserving valid array indexing (`arr[0]`). |
| **`math_openwebmath`** | `open-web-math/open-web-math` | Mathematics & LaTeX | **~5.0 GB** | ~2.83 GB (21 parts) | Removes crawler HTML/XML comments, testsuite tags, and web citation brackets while keeping LaTeX syntax intact. |
| **Total Pretrain** | | | **~24.5 GB raw text** | **10.12 GB Parquet** | Overall deduplicated, token-ready corpus. |

## 4. Tier 2: Supervised Fine-Tuning (SFT / ChatML)

All instruction-following corpora are unified into the standardized **ChatML format**:

```json
{
  "messages": [
    {"role": "system", "content": "You are OutMind, an open-source lightweight AI created by Mesosfer-AI."},
    {"role": "user", "content": "Bagaimana cara kerja Grouped Query Attention?"},
    {"role": "assistant", "content": "Grouped Query Attention (GQA) membagi query heads ke dalam kelompok yang berbagi pasangan key dan value heads..."}
  ],
  "source": "id_aya",
  "num_turns": 3
}
```

### Supported SFT Domains:
1. **Indonesian Instruction**: `CohereForAI/aya_dataset` (Indonesian subset), sanitized of legacy `<unk>` tokens.
2. **Chinese Instruction**: `m-a-p/COIG-CQIA` (Chinese open instruction general split).
3. **English Multi-Turn Dialogue**: `HuggingFaceH4/ultrachat_200k` (high-quality multi-turn conversations).
4. **Mathematical Chain-of-Thought**: `meta-math/MetaMathQA` (GSM8K/MATH augmented solutions).
5. **Code Instruction**: `ise-uiuc/Magicoder-Evol-Instruct-110K` (Python/polyglot synthetic instructions).
6. **Tool & Function Calling**: `glaiveai/glaive-function-calling-v2` (structured function-calling agent dialogues).
7. **Identity Grounding**: Handcrafted Mesosfer-AI OutMind persona grounding examples.

### Online Deduplication
During ingestion, an MD5 hash of the initial user turn is dynamically indexed. If an identical prompt is encountered from another slice or duplicate record, it is immediately discarded to prevent overfitting on repetitive instruction templates.

## 5. Tier 3: Validation Benchmarks (Zero Contamination)

To evaluate OutMind objectively against global Small Language Models (such as Qwen 2.5 0.5B, SmolLM 135M, and Llama 3.2 1B), four core benchmarks are preserved **without any text modification**:

* **TyDiQA (`id_tydiqa.jsonl`)**: Measures Indonesian reading comprehension and factual question answering.
* **GSM8K (`math_gsm8k.jsonl`)**: Evaluates multi-step mathematical reasoning via Chain-of-Thought (CoT) and `#### <number>` exact-match answer extraction.
* **HumanEval (`code_humaneval.jsonl`)**: Python code generation pass@k benchmark evaluated using native Python AST parsing and unit test execution (`check(candidate)`).
* **MMLU (`general_mmlu.jsonl`)**: Broad 57-subject multidisciplinary knowledge benchmark evaluated using 4-choice log-likelihood scoring.

## 6. How to Use the Dataset

### Loading via Hugging Face Datasets (Python)

```python
from datasets import load_dataset

# 1. Stream Pretraining Documents (Low RAM)
pretrain_stream = load_dataset(
    "Mesosfer/outmind-dataset",
    data_dir="pretrain",
    split="train",
    streaming=True,
)
for sample in pretrain_stream:
    print(f"Source: {sample['source']} | Length: {sample['char_len']:,} chars")
    break

# 2. Load SFT Dialogues
sft_ds = load_dataset(
    "Mesosfer/outmind-dataset",
    data_dir="sft",
    split="train",
)
print(f"Total SFT Dialogues: {len(sft_ds):,}")
```

### Training the OutMind Tokenizer on the Dataset

Train a custom BPE tokenizer with Indonesian regex optimization directly from the pretraining Parquet files without extracting raw text files:

```powershell
.venv\Scripts\python.exe scripts/train_tokenizer.py --parquet-dir data/cleaned/pretrain --vocab-size 64000
```
